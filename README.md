## 🚀 How to Host on GitHub Pages (Step-by-Step)

Because this website is built with pure, modern, zero-dependency HTML5, CSS3, and JavaScript, it can be hosted **100% free** on GitHub Pages in under 2 minutes:

### Step 1: Create a New GitHub Repository
1. Go to [github.com/new](https://github.com/new).
2. Name your repository (e.g. `portfolio` or `Lone-entity.github.io`).
3. Set the repository to **Public**.
4. Leave "Add a README file" unchecked and click **Create repository**.

### Step 2: Push Your Code
Open your terminal in this folder (`d:\poertfolio website`) and run:
```bash
git init
git add .
git commit -m "feat: initial commit of executive portfolio website"
git branch -M main
git remote add origin https://github.com/Lone-entity/YOUR_REPO_NAME.git
git push -u origin main
```
*(Replace `YOUR_REPO_NAME` with your actual repository name)*

### Step 3: Activate GitHub Pages
1. Go to your repository settings on GitHub: **Settings** -> **Pages** (in the left sidebar).
2. Under **Build and deployment** -> **Branch**, select `main` and `/ (root)` folder.
3. Click **Save**.
4. Your website will be live in ~60 seconds at:
   ```
   https://lone-entity.github.io/YOUR_REPO_NAME/
   ```
   *(Or `https://lone-entity.github.io/` if your repository was named `Lone-entity.github.io`)*

## ⚡ Hosting on Vercel or Render (Alternative Options)

- **Vercel:**
  1. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
  2. Import your GitHub repository.
  3. Keep default settings (Framework: Other) and click **Deploy**.
  
- **Render:**
  1. Go to [render.com](https://render.com) and click **New +** -> **Static Site**.
  2. Connect your GitHub repository.
  3. Set Publish directory to `./` and click **Create Static Site**.
